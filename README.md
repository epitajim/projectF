# Fラン大学は日本の宝プロジェクト — サイト運用メモ

## 構成

```
site/
├── index.html                  # トップページ(基本情報・新着・リサーチ一覧・今後の展開)
├── news.js                     # 新着情報データ(ここに追記するだけで反映)
├── README.md                   # このファイル
└── research/
    └── bf-hojokin/
        └── index.html          # 「BF大学と補助金の関係」DB(データ埋め込み・自己完結)
```

すべて静的ファイル。ビルド不要。相対パスのみ使用しているので、GitHub Pages のサブパス
(`https://<ユーザー名>.github.io/<リポジトリ名>/`)でも独自ドメインでもそのまま動きます。

## 更新のしかた

- **新着情報を足す**: `news.js` の `NEWS` 配列の先頭に1行追加してコミット。
- **リサーチを足す**: `research/<スラッグ>/index.html` を作り、トップの「リサーチデータ」
  セクションにカードを1枚追加、`news.js` に告知を1行追加。
- **来年のデータ更新**: 新しいPDFから同じ手順でデータを再生成し、
  `research/bf-hojokin-2027/` のように年度別ディレクトリで併存させるとアーカイブになる。

## GitHub Pages 公開手順

1. GitHub で新規リポジトリを作成(例: `f-ran-takara`、Public)
2. この `site/` フォルダの中身をリポジトリ直下にアップロード
   (Web UIなら "Add file → Upload files" にドラッグ&ドロップ)
3. Settings → Pages → Branch: `main` / `(root)` → Save
4. 数分後 `https://<ユーザー名>.github.io/f-ran-takara/` で公開

## 将来の拡張の設計方針

| 機能 | 推奨アプローチ |
|---|---|
| 新着情報の本格化 | 当面は news.js。記事が増えたら Astro などの静的サイトジェネレータへ移行(構成はそのまま移せる) |
| 記事の寄稿 | 受付: Googleフォーム or GitHub Issue テンプレート。掲載: `articles/` ディレクトリを新設 |
| オンラインショップ | BASE / STORES / Booth の外部ショップを開設しトップからリンク(決済を自前で持たない) |
| 大学別ページ | `univ/<大学名スラッグ>/` を機械生成(既にある final.json 相当のデータから生成可能) |
| 独自ドメイン | リポジトリに CNAME ファイルを置き、DNSでCNAME設定(GitHub Pagesは無料でHTTPS対応) |

## 注意(重要)

- 入試難易度データは河合塾の予想値に基づく二次利用です。**公開範囲・引用表記について
  権利上の懸念がないか、公開前に一度確認することを推奨します**(出典明記は最低限必須)。
- 補助金データは公表資料由来ですが、金額の引用時は一次資料の確認を促す注記を残すこと。
